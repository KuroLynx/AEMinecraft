## AEMinecraft v0.7.0-rc.1

**Pre-release.** This is a test build of v0.7.0, so expect rough edges. Please report anything odd. The new in-game report button (see below) makes that a two-click job. Stay on v0.6.2 if you want a stable game.

v0.7.0 brings Minecraft 26.2 and 26.3, a rewritten logic engine, and a long list of checks that now ask for what the game actually requires.

### New

- **Minecraft 26.1.2, 26.2 and 26.3.** One mod jar per Minecraft version; download the one that matches your game. Each player picks their version in the YAML:
  ```yaml
  minecraft_version: '26.3'
  ```
  The mod refuses to enter a world generated for a different Minecraft version, naming both. With BACAP on, install the pack release made for your version: **1.20.3** for 26.1.2, **1.21** for 26.2, **1.21.1** for 26.3.
- **Report a logic error from the advancement screen.** Click the book button, then the advancement that looks wrong. Choose "wrong logic" or "should not be accessible yet" and add a note if you want. The report is saved to `<world>/archipelago/logic_reports/` with everything needed to reproduce it. Send that folder along with your report.
- **2x2 crafting is gated too.** When the crafting table is a Knowledge gate, your own 2x2 inventory grid crafts nothing until you receive **Knowledge: Crafting Table**, planks and sticks included. This is the new `inventory_crafting` route of `item_gate_behavior`, on by default.
- **Knowledge: Composter.** A new Knowledge gate: filling or emptying a composter, including a village one, needs it.
- **Generation progress.** Generating now prints each AEMinecraft player's steps and how long they took.

### Changed

- **The Biome Finder covers every biome-bound thing.** The common biomes are plains, forest, birch forest, river, ocean and beach. Anything found only outside them needs the Biome Finder when it is enabled, or a structure that contains it. That covers blocks and mobs alike: cactus, bamboo, sweet berry bushes, sea pickles, powder snow, husks, camels, foxes, llamas, polar bears, armadillos and more. Nether and End content is gated by reaching that dimension instead.
- **Inventory Lock: locked slots stop you wearing or holding, not obtaining.** You can still pick up armor with the armor slots locked; you just can't put it on. Checks that need you to wear or hold something now wait for that slot. **`mode: fixed` is removed**: its permanently locked slots made some checks impossible.
- **Traps arrive 10–20 s apart** (was 30–60 s). Still never two at once.

### Fixed

**Checks that were in logic too early:**

- **Anything that needs an item in your hand** now needs a free inventory slot to hold it. With every slot locked at the start, the first Progressive Inventory Slot could otherwise land on a check you couldn't do.
- **Stacks need a source that doesn't run dry.** A check asking for 16 or more of something no longer counts a few chests. Master Coal Miner and Paleontologist need a renewable source.
- **Tools.** Several routes reached pickaxe-gated items without a pickaxe. Blocks that only drop to the right tool now ask for it: shovels for snow, a sword or shears for cobwebs, shears for glow lichen, grass and dead bushes.
- **Riding a nautilus** needs it tamed, so a pufferfish (Coralful Shell).
- **The Devil's Distance and Subspace Bubble** need the Overworld. On a Nether start they were in logic before it.
- **Core Keeper** needs the Trial Chambers, **Flashy Items** a glow squid, and **You're doing it wrong** a shulker.
- **Concrete** needs its powder and dye. A **worn anvil** needs an anvil.
- **Villager trades** are priced at the trade level that offers them.

**Mod:**

- `bacap_rewards: false` could leave BACAP's rewards on in a brand new world.
- The swap-offhand key, the screen swap keys and right-click equipping could put items into locked slots.

### Upgrading

- **Update both the apworld and the mod.** v0.7.0 seeds use content and gates the v0.6.2 mod doesn't know.
- **YAML:**
  - `minecraft_version` is new. Leaving it out means **26.1.2**. Write it quoted, as above.
  - `inventory_lock: mode: fixed` is no longer accepted. Use `progressive` or `disabled`.
  - `item_gate_behavior` gains `inventory_crafting` (default `true`). It only matters when the crafting table is in your `knowledge_gates`.
  - The template now pins `requires: game: AEMinecraft: 0.7.0`, so an older apworld refuses it.
- **Seeds generated with v0.6.x** should be finished with the v0.6.2 mod.

### Worth testing in this RC

- **Minecraft versions:** 26.2 and 26.3 worlds, joining and playing, with and without BACAP.
- **Gates:** the 2x2 crafting gate with Knowledge: Crafting Table gated, the inventory slot locks, and the composter gate.
- **Report button:** one report sent from the advancement screen.
